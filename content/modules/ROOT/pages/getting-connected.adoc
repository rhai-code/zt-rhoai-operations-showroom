== Environment Access

Your workshop environment is pre-provisioned from the RHOAI Deploy & Configure workshop. Use the credentials below to access your cluster.

=== OpenShift Console

Open the OpenShift web console at:

image::01-console-home.png[OpenShift web console home, logged in as the admin user with the Administrator perspective and cluster status visible,link=self,window=blank,width=800]

{openshift_console_url}

Log in with:

* **Username**: `{user}`
* **Password**: `{password}`

=== OpenShift CLI

Open the terminal on the right side of this page and log into OpenShift:

[source,bash,role="execute",subs="specialcharacters,attributes"]
----
oc login -u {user} -p {password} {openshift_api_url}
----

=== Verify RHOAI Is Running

Confirm that the RHOAI operator and DataScienceCluster are healthy:

[source,bash,role="execute"]
----
oc get datasciencecluster -A
----

image::02-dsc-ready.png[oc get datasciencecluster -A output: the default-dsc DataScienceCluster with READY True,link=self,window=blank,width=800]

You should see a DataScienceCluster resource with `Phase: Ready`.

[source,bash,role="execute"]
----
oc get csv -n redhat-ods-operator | grep rhods
----

image::03-rhods-csv.png[oc get csv output: the RHOAI operator ClusterServiceVersion with Succeeded phase,link=self,window=blank,width=800]

Confirm the RHOAI operator CSV shows `Succeeded`.

=== Clone the Workshop Manifests

The manifests referenced by the `oc` commands in later modules live in the workshop repository:

[source,bash,role="execute"]
----
git clone https://github.com/rhai-code/zt-rhoai-operations-showroom.git ~/zt-rhoai-operations
cd ~/zt-rhoai-operations
ls manifests
----

You should see the per-module folders (`01-ops-patterns`, `02-idp-users-groups`, `03-models-assets-scale`).

image::05-clone-manifests.png[ls manifests output showing the per-module manifest folders,link=self,window=blank,width=800]

[NOTE]
====
All `manifests/...` paths in later modules are relative to the repository root
(`~/zt-rhoai-operations`). Make sure you are working from that directory when you
run them.
====
